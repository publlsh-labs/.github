# Tinduck Labs brand kit v1.0

All artwork is SVG. Logos and wordmarks are outlined paths (no fonts needed).

| Folder | Contents |
|---|---|
| logo/primary | Horizontal lockup: color, black, white, reversed (on charcoal), color on white |
| logo/stacked | Icon above wordmark: color, black, white, reversed |
| logo/wordmark | "Tinduck Labs" without the symbol: color, black, white, reversed |
| icon | Symbol only: color, black, white, reversed |
| app-icons | 1024px app icons: charcoal, white, orange (rounded and full-bleed) |
| favicon | favicon.svg (switches to white in dark mode) and a charcoal-tile version |
| social | Avatars, LinkedIn banner, X header, Open Graph image (dark and light) |
| guidelines | brand-overview, color-palette, logo-usage (clear space, minimum size, misuse) |
| colors.css / colors.json | Colour tokens |

## Colours
Charcoal #171717 · Beak orange #FE7909 · White #FFFFFF · Mist #F4F4F2 · Slate #6B6B66

## Notes
- Vectors were traced from the supplied PNG, so tiny curve irregularities are possible. For print or signage, have a designer refine the paths once.
- Guideline sheets use a system sans font for their captions.
- Orange values were sampled from the original artwork.
